# PhonePe-Analysis-Dashboard-Using-PowerBI
An interactive Power BI dashboard designed to analyze PhonePe transaction data and uncover insights into transaction trends, payment performance, customer demographics, and service-wise transaction values.

Key Features:

📊 KPI cards for Total Transactions, Transaction Value, Unique Users, and Success Rate
📈 Monthly transaction and transaction-value trend analysis
👥 Age-segment analysis across Millennials, Gen X, Gen Z, and Boomers
💳 Payment-status analysis for Failed, Pending, and Successful transactions
🏦 Service-wise transaction value analysis
👤 Top users based on transaction value
📅 Weekday vs. weekend transaction analysis
🔍 Interactive month and payment-status filters
💡 Key business insights highlighted directly on the dashboard

Tools & Technologies: Power BI | Power Query | DAX | Data Visualization | Data Analysis
